# Шпаргалка для турагента — Тревелон

Лендинг-презентація на базі Google Slides «Шпаргалка для турагента від Тревелон».
16 повноекранних секцій, керування з клавіатури, придатна для показу на проекторі.

## Структура

```
.
├── index.html          ← увесь лендинг: розмітка, стилі, скрипти
├── extract-images.py   ← витягує фото з .pptx у assets/raw/
├── assets/             ← сюди покласти фото (див. нижче)
└── README.md
```

## Керування під час показу

| Клавіша | Дія |
|---|---|
| `→` `↓` `Space` | наступна секція |
| `←` `↑` | попередня |
| `F` | повний екран |
| `Home` / `End` | на початок / у кінець |

Праворуч — рейка секцій (клікабельна), зліва внизу — назва блока й номер,
зверху — смуга прогресу.

Разом ≈ 1,9 МБ. Слайди 3–5 (Хургада, Шарм, Марса-Алам) фотографій в оригіналі
не мали — там фірмовий градієнт із логотипною текстурою.

`extract-images.py` залишений у репозиторії на випадок, якщо презентацію
оновлять і фото доведеться перезабрати:

```bash
python3 extract-images.py Шпаргалка_для_турагента_від_Тревелон.pptx
```

Він складе всі картинки в `assets/raw/` з іменами вигляду `slide06-img1.png`,
щоб було видно, з якого слайда кожна.

## Публікація на GitHub Pages

```bash
git init
git add .
git commit -m "Шпаргалка для турагента — лендинг"
git branch -M main
git remote add origin git@github.com:<user>/<repo>.git
git push -u origin main
```

Далі: **Settings → Pages → Source: Deploy from a branch → main / (root)**.
Через хвилину сторінка буде на `https://<user>.github.io/<repo>/`.

## Шрифти й показ без інтернету

Сторінка тягне Nunito Sans та IBM Plex Mono з Google Fonts. Якщо на заході
може не бути мережі — завантажте `.woff2` у `assets/fonts/`, замініть `<link>`
у `<head>` на локальні `@font-face`, і сторінка працюватиме повністю офлайн
(відкривши `index.html` подвійним кліком).
